# พยากรณ์สภาพคล่อง (Liquidity Forecast)

เว็บแอปสำหรับบอร์ด/ฝ่ายการเงินของสหกรณ์ออมทรัพย์ ใช้พยากรณ์กระแสเงินสดสุทธิและยอดเงินสดคงเหลือ
ล่วงหน้า 3–6 เดือน จากข้อมูลย้อนหลังที่อัปโหลดเป็น CSV/Excel เพื่อดูว่าเงินสดสำรองจะพอจ่ายถอนเงินฝาก
และเงินกู้ที่อนุมัติแล้วหรือไม่

## โครงสร้างโปรเจกต์

```
backend/    FastAPI + pandas — อ่านไฟล์, คำนวณพยากรณ์และ backtest (stateless, ไม่มีฐานข้อมูล)
frontend/   HTML/CSS/vanilla JS + Chart.js (vendor แนบมาในโปรเจกต์ ไม่ต้องพึ่ง CDN ภายนอก)
sample_data/  ไฟล์ CSV ตัวอย่าง (ข้อมูลสังเคราะห์ ไม่ใช่ข้อมูลจริงของสหกรณ์ใด) สำหรับทดลองใช้งาน
```

## วิธีรัน

```bash
cd backend
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

เปิดเบราว์เซอร์ไปที่ `http://localhost:8000` — หน้าเว็บ (frontend) และไฟล์ตัวอย่าง (sample_data)
ถูกเสิร์ฟจากเซิร์ฟเวอร์เดียวกัน ไม่ต้องรันแยก ไม่ต้องตั้งค่าฐานข้อมูล

## การใช้งาน

1. อัปโหลดไฟล์ CSV/Excel ย้อนหลัง (แนะนำ ≥24 เดือน) หรือกดปุ่ม "ตัวอย่าง 24 เดือน" / "ตัวอย่าง 6 เดือน" เพื่อทดลอง
2. จับคู่คอลัมน์ในไฟล์กับฟิลด์ที่ระบบต้องการ (ระบบเดาให้เบื้องต้นแล้ว) และกำหนดจุดต่ำสุดของเงินสดที่ยอมรับได้
3. ดูแดชบอร์ด: กราฟเงินสดคงเหลือย้อนหลัง+พยากรณ์พร้อมช่วงความไม่แน่นอน, ตารางเปรียบเทียบวิธีพยากรณ์ (MAPE),
   การ์ดสรุป และคำเตือนความแม่นยำ (ถ้ามี) — ปรับจุดต่ำสุดบนแดชบอร์ดได้ทันทีโดยไม่ต้องอัปโหลดใหม่

## หมายเหตุเรื่องข้อมูลตัวอย่าง

ไฟล์ใน `sample_data/` เป็นข้อมูลสังเคราะห์ที่สร้างขึ้นเพื่อทดสอบระบบเท่านั้น ขนาดตัวเลขอ้างอิงคร่าวๆ จาก
ระดับสินทรัพย์ของสหกรณ์ขนาดใหญ่ (หลักหมื่นล้านบาท) แต่ไม่ใช่ตัวเลขจริงของสหกรณ์ใดๆ เมื่อใช้งานจริง
ให้อัปโหลดรายงานกระแสเงินสดของสหกรณ์เอง (ไม่ใช่งบทดลอง/trial balance โดยตรง เพราะต้องแปลงเป็นยอด
เงินฝากเข้า-ออกและเงินกู้เบิกจ่าย-รับชำระคืนรายเดือนก่อน)
